# customer-registration-form-vb6

Aplicação desktop legada desenvolvida em Visual Basic 6 para operações de cadastro e gerenciamento de clientes, utilizando os recursos tradicionais de formulários do Windows.

## Sobre o Projeto

Aplicação desktop legada desenvolvida em Visual Basic 6 para operações de cadastro e gerenciamento de clientes, utilizando os recursos tradicionais de formulários do Windows.

## Tecnologias Utilizadas

- Visual Basic 6 (VB6)
- ADO (ActiveX Data Objects)
- VBRuntime
- Microsoft Access (.mdb) ou SQL Server via ODBC/OLE DB

## Funcionalidades

- Inclusão de clientes
- Alteração de registros
- Remoção de registros
- Utilização de formulários MDI e modais, conforme implementado

## Arquitetura do Projeto

Arquitetura modular tradicional do VB6, baseada em Forms, módulos (.bas) e classes (.cls).

## Banco de Dados

Microsoft Access (.mdb) ou SQL Server por meio de ODBC/OLE DB, conforme a configuração do projeto.

## Como Executar

1. Clone ou baixe o repositório.
2. Abra o projeto no ambiente Microsoft Visual Basic 6 compatível.
3. Verifique as referências e componentes ActiveX necessários.
4. Configure o caminho do arquivo Access ou a conexão ODBC/OLE DB com o SQL Server.
5. Compile e execute o projeto em um ambiente compatível com VB6.

## Aprendizados

- Manutenção e desenvolvimento de aplicações legadas.
- Programação com Visual Basic 6.
- Acesso a dados utilizando ADO.
- Organização modular com formulários, módulos e classes.
